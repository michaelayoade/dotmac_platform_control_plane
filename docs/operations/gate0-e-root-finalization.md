# Gate 0 original-root E finalization source contract

The original root supervisor prepares encrypted E evidence after successful
same-invocation bootstrap completion and before waiting for the original JIT
runner to exit. This source amendment does not execute a campaign, install
credentials, qualify a host or accept E. Genuine static/native qualification and
separate operational approval remain required. Public-only publication adoption
does not authorize execution of this root preparation path.

`initialize_original_export()` and `prepare_original_export()` are fixed,
argument-free owners. Initialization validates the original supervisor and
independently qualified static writer profile, then creates the fixed transfer
ticket before JIT starts. Preparation loads the real root writer factory, runs
its retained-byte, historical, live producer and encryption checks, and invokes
the fixed transfer owner with the same original bounds, boot, campaign, lifecycle
binding, courier UID/GID, static-profile digest and source-bundle digest. Neither
entry accepts paths, callbacks, caller facts, qualification flags or receipt JSON.

## Static authority and actual runtime observations

The fixed profile and binding are
`/etc/dotmac-gate0-e/root-static-profile.json` and
`/etc/dotmac-gate0-e/root-static-binding.json`. The writer owns their closed
parsing and external source/native qualification. Static policy, public trust,
recipient, original retained evidence and source selection cannot be overridden
by runtime observations. Qualification explicitly covers
`original-root-static-profile-export-encryption.v1` and the full measured source
roster, including bootstrap, lifecycle, supervisor, transfer and this module.

Only manifest, file pins, completion and actual bootstrap invocation are assembled
inside the writer from the supervisor's fixed original root-owned export. The
reader verifies stable descriptors, exact bytes, ownership, modes and identities,
then joins actual successful inactive bootstrap manager state and retained
completion to original collector, campaign, boot and lifecycle observations.
No source-generated native receipt or per-run human qualification is introduced.

## One original absolute end

The installed bootstrap v2 contract consumes the same externally qualified
immutable lifecycle original bounds before it starts. It verifies exact selected
A/B scope and original UTC finalization no later than B expiry plus two seconds.
Its timer derives from the original monotonic end without resampling wall time.
The manager completion, owned-file retirement, writer and pre-JIT ticket must
join the same floor(end × 1,000,000). An earlier original end stays earlier.

All existing phase limits are clamped by that original end, including historical
reads, the 90-second live producer read, encryption and output. Root finalization
adds no 180-second tail. Failed or incomplete bootstrap refuses before writer
preparation. Successful preparation does not end the supervisor: it waits for
normal JIT exit within the original end, then performs the existing positively
owned secret/JIT retirement.

## Private export and encrypted handoff

The original collection/process/owned-file/manifest export directory is now
root:root0700 with root:root0600 files. Previously its root:courier group0750
and0640 modes exposed private export bytes to the courier; that confidentiality
finding is repaired narrowly. Other startup/completion delivery defaults are
unchanged. The fixed bootstrap completion and its retained pending hardlink are
root-private and verified as the same inode. Plaintext staging under
`/run/dotmac-gate0-e/staging` remains root-only0700.

Only the transfer owner's exact ciphertext/public-projection pair becomes
root:courier_gid readable at `/run/dotmac-gate0-e-transfer` (0750, files0640).
Its fixed ticket/ready records under `/run/dotmac-gate0-e-transfer-state` are0640;
the private manifest is0600. Ticket, ready, manifest and encrypted pair remain
as evidence, including incomplete failure state. There is no delete/rearm API
or claim that all task files are removed. Original secret retirement remains
separate; future VM retention/cleanup policy owns residual noncredential evidence.

## Source verification limits

Authored tests compose actual protected static/lifecycle/bootstrap loaders and
root manifest/completion predicates with typed manager, HTTP, GPG and native-file
seams. They cover the real writer prepare path, live-stage ordering, deadline
exhaustion, private export permissions, wrong source/UID/boot/campaign/window and
bootstrap failure. They are not executed in this preparation. Only AST parsing
and pinned Ruff0.6.9 are run. Native clock/manager behavior and actual operational
installation remain unproven until separately qualified.
